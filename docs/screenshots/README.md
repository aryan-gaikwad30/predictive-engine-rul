# Project Screenshots

This directory is designated for storing product preview images and UI screenshots used in the project documentation and `README.md`.

## Recommended Screenshots & Naming Conventions

To keep documentation clean and organized, consider saving screenshots with the following filenames:

1. **`hero_dashboard.png`** / **`hero.png`**
   - Overview of the application landing page / hero view.
2. **`dataset_configuration.png`**
   - Dataset upload, schema profiling, and target RUL configuration.
3. **`training_progress.png`**
   - Model training execution and real-time status.
4. **`fleet_health.png`**
   - Fleet-level RUL predictions, degradation curves, and health index gauges.
5. **`model_story.png`**
   - Validation performance metrics, error distributions, and NASA score breakdown.

---

## How to Link in README.md

You can embed screenshots directly into markdown:

```markdown
![Hero Dashboard](docs/screenshots/hero_dashboard.png)
```
